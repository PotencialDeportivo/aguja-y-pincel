# Aguja y Pincel

Web estática para el proyecto artesanal Aguja y Pincel.

## Publicación
- HTML y CSS en un único `index.html`.
- En Render: Static Site.
- Build command: vacío.
- Publish directory: `.`
- Rama: `main`.

## Pendiente antes del lanzamiento definitivo
- Sustituir las ilustraciones provisionales por fotografías reales de los productos y de las pinturas.
- Añadir contacto real y enlaces sociales.
- Confirmar precios, medidas, materiales, cuidados, disponibilidad y condiciones de envío/venta.
- Añadir los textos legales y de privacidad que correspondan.
- Conectar el dominio propio cuando la web esté revisada.
